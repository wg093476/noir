Refund policy

Last updated

In short: a digital code can't be returned once it's delivered, so delivered orders are final. If we can't deliver your code, you're refunded automatically. If a code we delivered doesn't work, we fix it.

1. Codes we couldn't deliver

If our supplier can't provide your gift card after you pay, we cancel the order and refund the full amount, service fee included, to the card or wallet you paid with. This happens automatically, usually within minutes. Your bank may take 5–10 business days to show it.

2. Delivered codes are final

Once a code is shown on screen or emailed to you, it can be used right away by anyone who has it. So we can't accept returns, exchanges or refunds for a delivered code. That includes a wrong brand or amount picked by mistake, or a code you no longer want. Please check your brand, amount and email before paying.

3. A code that doesn't work

If a code shows as invalid, already used or the wrong value when you first try it:

  1. Email within 7 days of your order, with a screenshot of the error.
  2. We check the code with our supplier, usually within 1–3 business days.
  3. If the code is confirmed faulty, we send a working replacement or give you a full refund.

We can't refund codes that were redeemed, shared, or used on the wrong country's store. US cards only work on US accounts.

4. Crypto payments

Crypto payments can't be reversed automatically. If a crypto order qualifies for a refund under this policy, we send it in the same coin to an address you give us, minus the network fee. If you underpay, no code is sent. Contact us and we'll help you finish the payment or return what you sent, minus network fees.

5. Disputes and chargebacks

Please contact us before disputing a charge with your bank. We can usually fix the problem faster. If a charge is disputed for an order that was delivered, we'll share the delivery records with the payment provider.
